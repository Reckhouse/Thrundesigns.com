## Important architectural decisions to preserve

- Implement **inside** `packages/controlled-chaos`, not `src/components/poster-lab/`
- Persistence remains **Blob JSON + optional Redis metadata**
- Do not introduce Neon/Postgres just for creations
- Keep server-safe files free of Three/R3F/browser-only imports
- Frame loops should mutate refs/uniforms, not React state
- Local audio bytes must never persist or go to analytics
